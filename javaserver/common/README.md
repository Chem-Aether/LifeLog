# common 公共模块

`common` 是 Java Maven 公共库，不是可独立启动的微服务，也不拥有数据库。它只承载多个 Java 服务共享的基础设施代码。

## 当前职责

- 统一 API 响应结构及通用异常处理。
- CORS、OpenAPI 等跨服务基础配置。
- JWT 请求过滤和令牌校验；认证服务负责签发，业务服务在本地验证。

## 边界约定

业务 DTO、业务实体、业务 Mapper、业务规则和业务数据库表应留在各自服务内。只有确认被多个服务共同使用且语义稳定的基础代码才放进此模块，避免公共模块反向依赖具体业务服务。

改动后从 `javaserver/pom.xml` 构建依赖该模块的目标服务；无需单独运行 `common`。
